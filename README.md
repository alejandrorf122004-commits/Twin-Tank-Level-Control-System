# Twin Tank Level Control System

Coupled-tank control project with CAD, MATLAB, Python GUI, observer design and PLC-oriented implementation.

## Purpose

This project documents the modeling, simulation and control of a twin-tank hydraulic system used to study process control and reference tracking.

## What is included

- `CAD/`: mechanical design, assemblies and PCB references.
- `MATLAB/`: modeling, controller design and observer work.
- `Python_GUI/`: interface for simulation and data analysis.
- `Documentation/`: final report and supporting documents.
- `Images/`: CAD renders, GUI captures and prototype photos.

## Main focus

- Second-order process modeling
- PID and state-space control
- State observer design
- Servosystem implementation
- GUI support for analysis and validation

## Current status

The repository presents the project as a technical control-system development with documentation, simulations and prototype evidence.
